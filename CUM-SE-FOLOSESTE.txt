ChefAcasă - CUM PORNEȘTI APLICAȚIA
=====================================
1. Dă dublu-click pe start.bat -> se deschide http://localhost:8000
   (recomandat: așa merg chatul AI, traducerea, instalarea pe telefon)
   Sau dublu-click direct pe index.html (unele funcții online pot fi limitate)

CE ȘTIE SĂ FACĂ:
- 🔍 Caută rețete după ingrediente (baza locală + TheMealDB + butoane internet)
- 🥗 Filtru dietă: vegetarian / post / fără gluten / ușor (<400 kcal)
- 🔥 Calorii estimate per porție (orientativ, calcul local)
- ⚖️ Porții ajustabile (−/+) cu recalcularea cantităților
- 🍳 Mod gătire: pași mari, timer cu alarmă, citire vocală
- 📅 Meniu săptămânal (Luni-Duminică) + generare automată
- 🛒 Listă de cumpărături automată + manuală, grupată pe raioane, copiere, WhatsApp
- 📖 Rețetele mele: le adaugi, le editezi, le ștergi, apar la căutare
- 🌐 Traducere EN→RO automată (Google gratis) + buton manual
- 🔊 Citește rețeta cu voce tare
- 💬 Chat Asistent AI (proxy Cloudflare + fallback local), limbă RO/EN, mod comic/piperat
- 📱 Instalabil pe telefon: din meniul Chrome „Adaugă pe ecranul de pornire”
- ❤️ Favorite, RO/EN, trimitere rețetă pe WhatsApp / tipărire rețetă
- 💾 Backup / restaurare JSON din ⚙️ Setări

DATELE (favorite, meniu, listă, rețetele mele) stau DOAR în browserul tău.
Fă backup regulat: ⚙️ Setări -> ⬇️ Descarcă backup (fișier JSON cu data).
Restaurare: ⚙️ Setări -> ⬆️ Restaurează + alegi fișierul.
